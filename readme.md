# PatchFiner 🔎

**PatchFiner** adalah aplikasi web single-file untuk memvisualisasikan dan membandingkan berbagai algoritma **pathfinding** pada sebuah grid.

Gunakan bagian **CLI / Live Formula** untuk melihat proses perhitungan algoritma secara langsung dan memahami bagaimana setiap algoritma mengeksplorasi grid hingga menemukan route.

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- DOM API
- LocalStorage

Project ini **tidak membutuhkan framework maupun dependency eksternal**.

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/bahrizalmulyawan/patchfiner.git
```

### Masuk ke Directory

```bash
cd patchfiner
```

### Jalankan Aplikasi

Buka file berikut menggunakan browser modern:

```text
patchfinder.html
```

Atau gunakan **Live Demo**:

https://bahrizalmulyawan.github.io/patchfiner/patchfinder.html

## 📁 Project Structure

```text
patchfiner/
└── patchfinder.html
```

Project dibuat sebagai **single-file web application** yang berisi HTML, CSS, dan JavaScript dalam satu file.

## 🎓 Educational Purpose

Project ini dibuat sebagai media visualisasi untuk membantu memahami bagaimana algoritma pencarian bekerja pada sebuah grid.

Dengan membandingkan berbagai algoritma, pengguna dapat mengamati perbedaan:

- Strategi eksplorasi
- Penggunaan heuristic
- Jumlah node yang diperiksa
- Panjang path
- Arah pencarian
- Proses pembentukan route

Visualisasi ini diharapkan dapat membantu pembelajaran konsep **pathfinding**, **graph traversal**, dan penggunaan **heuristic** secara lebih intuitif.
